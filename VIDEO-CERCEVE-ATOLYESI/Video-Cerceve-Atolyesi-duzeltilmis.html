İndirdikten sonra

  1. “HTML dosyasını indir” düğmesine bas.
  2. GitHub deponda istediğin klasörü aç.
  3. Add file → Upload files seç ve indirdiğin dosyayı yükle.
  4. Commit changes ile kaydet.
  5. GitHub Pages yayımladıktan sonra sayfanın bağlantısını Google Sites'a ekle.

Bu araç dosyayı otomatik olarak GitHub'a yüklemez. Her yeni video için farklı dosya adı kullan.
